Lagoon Genomics

Version 0.5 · Verschlüsselter DNA-Tresor

Private DNA-SNP-Analyse · iPhone-tauglich · kostenlos · ohne Cloud-Upload

1. Originaldatei auf deinem Gerät auswählen

MyHeritage / 23andMe SNP-Rohdaten im Text-/CSV-Format. Das Einlesen erfolgt ausschließlich im Browser-Arbeitsspeicher. Kein Upload. Nach einmaligem Import kannst du die gesamte Originaldatei passwortgeschützt dauerhaft auf diesem Gerät speichern.

Noch keine DNA-Datei verarbeitet.
Akzeptiert rsid/chromosome/position/genotype oder result. Dateien anderer Genome-Builds werden für genetische Interpretation gesperrt.

2. DNA-Tresor – nur einmal importieren

Originaldatei AES-256-GCM-verschlüsselt lokal im Speicher dieses Browsers aufbewahren. Das Passwort wird niemals gespeichert oder an einen Server gesendet. Künftige Besuche: Passwort eingeben, fertig.

Prüfe, ob bereits eine verschlüsselte DNA-Datei gespeichert wurde …

Wichtig: Safari kann Website-Speicher löschen. Sichere nach dem ersten Speichern unbedingt eine verschlüsselte .lgv-Backupdatei in der iPhone-App „Dateien“ oder deinem eigenen Backup-Speicher. Ohne Passwort ist das Backup nicht entschlüsselbar. Safari, Home-Screen-App und In-App-Browser können getrennte Datenspeicher verwenden.

Nur ein von dir bestätigter Speichervorgang legt verschlüsselte DNA-Daten ab. Der Dienstanbieter GitHub Pages erhält keine Rohdaten und keine Tresorschlüssel.

3. Recherchekandidaten

Datenschutz: Erst das bewusste Kopieren/Teilen überträgt ausgewählte Genotypen an ChatGPT oder andere Dienste. Die bloße Analyse tut das nicht.

4. Alle SNPs einzeln oder in Gruppen abfragen

Durchsuche alle eingelesenen rsIDs, nicht nur die zehn Forschungsmarker. Genotypen bleiben lokal. Mehrere rsIDs mit Leerzeichen, Komma oder Zeilenumbruch trennen (maximal 100).

5. Interpretationsgrenzen

Das Tool diagnostiziert weder Malabsorption noch einen Mikronährstoffmangel. Assoziationen mit Serumwerten sind nicht gleichbedeutend mit intestinaler Resorption. Fehlende SNPs, HLA-Haplotypen und seltene Krankheitsvarianten sind nicht negativ getestet.

Für persönliche Schlussfolgerungen braucht es zusätzliche Referenzallel- und Strangprüfung, populationsspezifische Studien sowie ggf. Laborwerte. Alle gezeigten Marker sind Forschungsansätze und keine bestätigten klinischen Befunde.

Quellcode und Tests im öffentlichen GitHub-PR. Die DNA-Datei wird niemals in das GitHub-Repository übertragen.
